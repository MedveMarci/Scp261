## [1.1.0]

- Added `spawn_only_once` to spawn SCP-261 at only one of the configured locations per round, using the `chance` values
  as weights
- Added `activation_items` to configure which items activate SCP-261 instead of just a coin
- Added `spawn_weapons_with_ammo` to dispense firearms empty, like SCP-1162

## [1.0.0]

- Released the plugin
